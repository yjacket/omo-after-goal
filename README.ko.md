# omo-after-goal

[English](README.md)

이 세션에 프롬프트 하나를 예약해 두고, 다른 세션의 goal이 끝나거나 지정한 시간이 되면 실행합니다. 푸터에는 무엇을 기다리는지와 기다리는 세션마다 남은 작업이 얼마인지를 알람 시계로 보여 줍니다.

## 설치

```sh
omo install C:/dev/omo/omo-after-goal
omo install git:github.com/yjacket/omo-after-goal
```

첫 번째는 로컬 클론을 설치하므로, 고친 내용이 다음 `/reload`에 바로 반영됩니다. omo가 패키지를 `<agentDir>/settings.json`의 `packages`에 등록합니다. 실행 중인 세션에서 `/reload`를 입력하세요.

`<agentDir>/extensions/after-goal.ts`에 예전 복사본이 남아 있으면 지우거나 옮기세요. 남겨 두면 확장이 두 번 로드됩니다. 그 예전 파일이 저장한 예약은 다음 시작 때 옮겨집니다.

## 사용법

`/after`를 입력하면 다른 세션에서 실행 중인 goal 목록 위에 선택기가 열립니다.

| 키 | 동작 |
| --- | --- |
| `↑` `↓` | 커서 이동 |
| `&` | 고른 goal을 현재 AND 그룹에 넣기 |
| `\|` | 고른 goal을 현재 그룹에 넣고, 다음 선택을 위한 새 OR 그룹을 열기 |
| `Enter` | goal을 고르고 확정; `시간 조건만` 줄에서는 지금까지 고른 goal로 확정(고른 것이 없으면 시간만 예약) |
| `Backspace` | 마지막 선택 되돌리기 |
| `Esc` | 취소 |

`&`가 `|`보다 강하게 묶입니다. `A &, B |, C Enter`는 `(A & B) | C`이고, A와 B가 모두 끝나거나 C가 끝나면 실행됩니다. goal만, 시간만, 또는 둘 다 고를 수 있습니다.

시간 줄은 기존과 같은 형식을 받습니다: `90m`, `2h`, `1h30m`, `2시간`, `23:30`. 시간 조건은 goal들과 OR로 묶입니다.

그다음 프롬프트 편집기가 열리고, 요약을 보여 준 뒤 확인을 받습니다.

- `/after now`는 조건과 상관없이 예약을 지금 실행하고 평소의 게이트를 거쳐 전달합니다.
- `/after cancel`은 확인을 받은 뒤 예약을 취소합니다.
- 예약은 세션마다 하나입니다. 다시 `/after`를 입력하면 지금 예약을 보여 주고 바꿀지 묻습니다. 프롬프트 편집기는 예전 프롬프트에서 시작합니다.

`/after`는 저장된 세션에서 동작합니다.

## 푸터

예약이 있는 동안 `omo-after-goal` 키로 푸터 상태 하나가 나타납니다:

```
⏰ omo-health 남은 4 & omo-desk 남은 2 | 23:30
```

기다리는 goal마다 그 세션의 프로젝트 이름과, 그 세션의 todo 중 아직 열려 있는 개수가 붙습니다. goal이 끝났으면 개수 자리에 `✓`, 세션이 더 이상 실행 중이 아니면 `꺼짐`이 오고, 시간 조건이 있으면 `| HH:MM` 부분이 붙습니다. 조건은 충족됐지만 프롬프트가 아직 전달 대기 중인 예약은 `⏰ 실행 대기`로 표시됩니다.

## 동작 방식

다른 세션이 쓰는 goal 파일(`<sessionsDir>/<slug>/extensions/goal/`)을 읽습니다. 끝난 goal은 예약에 래치되어, 그 세션이 종료돼도 끝난 상태로 남습니다.

남은 작업은 기다리는 세션의 로그에 있는 todo 도구의 구조화된 기록에서, 가장 최근 기록만 읽습니다. 그래서 지운 목록은 0으로 세고, todo 목록을 인용한 텍스트는 절대 읽지 않습니다. 사라진 goal 파일은 그 세션이 살아 있을 때만 끝난 것으로 세고, 완료·중단·교체된 goal은 세션이 종료된 뒤에도 셉니다.

푸터는 3초 주기 폴링으로 갱신하고, 표시 문구가 바뀌었을 때만 씁니다.

전달 방식은 그대로입니다. `/`로 시작하는 프롬프트는 Orca 터미널에 입력하고, 나머지는 사용자 메시지로 보냅니다. 세션이 바쁘거나 프롬프트 편집기가 비어 있지 않으면 전달하지 않고 기다리며, 대기 중인 전달은 재시작해도 남습니다.

## 제한

- 남은 시간은 추정하지 않습니다. 세는 것은 열려 있는 작업뿐입니다.
- 조건에는 괄호도 NOT도 없습니다.
- 개수는 기다리는 세션의 todo 목록이 todo 도구로 관리되고 있을 때만 나옵니다.
- PID는 다른 프로세스가 재사용할 수 있어, 죽은 세션이 살아 있는 것처럼 보일 수 있습니다.
- 세션이 브랜치를 되감은 뒤에는, 그 세션이 todo를 다시 쓸 때까지 버려진 브랜치의 개수가 보일 수 있습니다.

## 제거

```sh
omo remove C:/dev/omo/omo-after-goal
omo remove git:github.com/yjacket/omo-after-goal
```

첫 번째는 로컬 클론 설치, 두 번째는 git 설치를 제거합니다. 그다음 `/reload`를 입력하세요.
